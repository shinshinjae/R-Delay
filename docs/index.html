          거점별 지연 중인 작업 비율

          지연 중인 작업(배·차량·화물)의 비율입니다. 가는 가로선은 막힘 기준, 띠는 예상 범위(10번 중 8번)입니다.

          만약 이 요인이 평소였다면?

          요인을 하나씩 평소 값으로 되돌렸을 때의 지연 번짐 지수입니다. 점은 가운데 값, 가는 선은 예상 범위, 굵은 세로선은 1입니다.

            민감도(전문가)

            θ는 거점 규모 가정입니다. 육상·항공은 도메인 안에 거점이 하나라 θ의 영향이 해상 두 터미널에만 나타납니다.

            연쇄 기여도

            각 거점·연결이 지연 확산에 기여하는 몫(합계 1)입니다. 원의 크기는 거점 몫, 화살표 굵기는 거점 간 연결 몫입니다.

            거점별 기여 몫

            항공 반입 거점으로 번지는 지연(건)

            배가 부두 자리를 기다리는 시간

            대상 선박이 들어올 때 앞에 있는 선박 수의 분포입니다. 계산 방법은 작동 원리에 있습니다.

            도착 시각별 터미널 반출 소요

            가운데 값과 예상 범위(10번 중 8번)입니다. 점은 덜 걸리는 시간입니다.

            관측 기록(2시간 간격)

            관측이 들어올 때마다 계산 표본의 가중치를 고칩니다. 표본 상태(ESS)가 절반 아래로 떨어지면 표본을 다시 뽑습니다(재표본).

            시연용 가상 데이터

            합성 데이터 개념검증(TRL 3 수준)입니다. 실데이터는 아직 연동하지 않았습니다. 화면의 수치는 공개 보도로 확인한 사건 유형(장비 고장, 우회 물량, 명절 물량, 인력 결근)을 본뜬 합성 자료로 계산했으며, 특정 터미널·기업의 자료나 판정이 아닙니다(터미널 이름은 가상). 판단은 의사결정 지원용이고 최종 결정과 책임은 사용자에게 있습니다.
